# ZOO:CAFE v30 — External PNG Cafe Interior

카페 내부 전체를 외부 PNG 에셋 방식으로 전환한 버전입니다.

## 교체 파일
- `assets/cafe/interior/cafe-background.png` — 카페 내부 배경/가구/질감 전체
- `images/npc/cafe-owner.png` — 카페지기 NPC

같은 파일명으로 PNG를 덮어쓴 뒤 브라우저를 강력 새로고침(Ctrl+F5)하면 됩니다.
권장 카페 배경 크기: 960x540 PNG.

게임 충돌/이동/대화/출입 로직은 PNG와 분리되어 있습니다.
