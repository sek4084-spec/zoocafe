# ZOO:CAFE v46 — ZOO Garden Map

v45의 정상 작동하는 GPS/Google Maps 전환 구조를 유지하고 지도 표현만 ZOO:CAFE 스타일로 변경했습니다.

- 일반 POI/상점 라벨과 여러 기본 아이콘 숨김
- 도로: 따뜻한 크림/베이지
- 공원: 부드러운 연두
- 물: 파스텔 블루
- 텍스트: 브라운 계열
- 지도 상단 ZOO:CAFE / 현실 속 정원 브랜딩
- 지도 확대 범위 15~19
- 내 GPS 캐릭터와 주변 유저 거리 규칙 유지
- 카페 복귀 버튼은 하단 중앙으로 이동

Google 지도 데이터 자체는 유지하면서 게임용 시각 레이어로 보이도록 만든 1차 테마 테스트입니다.
