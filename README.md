# ZOO:CAFE v49 — Walkable 1km Garden

- 카페 밖으로 나오면 입장 시 GPS 위치를 중심으로 약 1km × 1km 고정 정원 생성
- 지도 줌/드래그 고정
- GPS는 주변 1km 사용자 판별용. 정원 캐릭터 이동에는 실제 GPS를 사용하지 않음
- 조이스틱/키보드로 지도 위 캐릭터 자유 이동
- 현실에서 1km 안에 접속한 사용자는 모두 정상 캐릭터로 표시 (실루엣 제거)
- 다른 사용자의 실제 GPS 좌표는 클라이언트에 전달하지 않음
- 게임 X/Y 좌표로 서로 걸어가 만나도록 변경
- 말풍선을 캐릭터 바로 위쪽으로 이동
- 큰 대화창 메시지에 작은 캐릭터 얼굴 추가
- 카페 복귀/말풍선/전체 채팅 기능 유지
