# ZOO:CAFE v48 — Conversation Garden

대화를 중심으로 정원 지도를 개편한 버전입니다.

- Google 지도 도로명/장소명 등 모든 기본 지도 라벨 숨김
- ZOO:CAFE 전용 장소 아이콘/명칭만 표시
- '카페로 돌아가기'가 nearby 모드에서 카페로 직접 복귀하도록 전용 게임 API 연결
- 지도 오른쪽에 말풍선 대화 버튼 + 전체 대화 버튼 추가
- 말풍선: 짧은 메시지를 보내면 지도 캐릭터 머리 위에 약 5초 표시
- 전체 대화: 화면 대부분을 사용하는 대형 채팅창
- 기존 WebSocket 채팅을 그대로 사용하므로 주변 사용자 채팅과 연동
- 500m/1km 주변 사용자 규칙 유지

주의: Google Maps 자체의 인증/결제 오류 팝업은 API 프로젝트 설정 문제이며 게임 UI로 숨기지 않습니다.
