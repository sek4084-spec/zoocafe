멍사자 데스크톱 펫 + 주카페 멀티 채팅 테스트

1. ZIP을 전부 압축 해제하고 Start-MungPet.cmd 실행 (Windows 10/11, 기본 Windows PowerShell 5.1 + .NET Framework).
2. 처음 뜨는 멍사자 채팅 창에 주카페 서버 주소를 입력하고 [주소 연결] 클릭.
   - 네 PC에서 서버를 실행 중: http://localhost:3000
   - 친구 PC: 네가 운영 중인 SAME 주카페 서버의 https:// 터널 주소를 입력. localhost는 친구 PC를 가리키므로 사용 불가.
3. 주카페 페이지가 열리면 각자 별도의 계정을 만들거나 로그인한 뒤 질문 퀘스트 화면에서 [연결 코드 받기]를 누르세요.
4. 12자리 연결 코드를 멍사자 창에 입력하고 [코드 연결] 클릭. 각자 자기 코드를 사용해야 합니다.
5. [멍사자 개인 대화]는 자기 계정의 멍사자 기억을 사용합니다. 다른 탭을 고르면 같은 주카페 서버의 애니 이야기관 / 게임 길드 / 생활 정보관 / 공용 채팅을 웹·친구 펫과 공유합니다.
6. 다음 실행부터는 저장한 서버 주소로 주카페를 자동으로 엽니다. 멍사자를 더블 클릭하면 채팅 창, 오른쪽 클릭하면 메뉴. 캐릭터는 드래그해 이동합니다.

호스트 PC: 기존 주카페 서버를 쓴다면 host-server 안의 새 파일로 기존 코드를 업데이트하고 기존 data 폴더와 .env 파일을 보존하세요. 새로 시작한다면 host-server/Start-Host.cmd를 실행하고, 별도 창에서 기존 터널을 실행하거나 cloudflared가 설치돼 있다면 host-server/Open-Public-Tunnel.cmd를 실행하세요. 터널에 출력된 HTTPS 주소를 두 사람의 멍사자 창에 입력하세요. 서버 실행 PC를 끄면 접속이 끊깁니다.

중요: ZIP 자체가 인터넷에 공개된 서버를 자동으로 만들지는 않습니다. 두 사람이 서로 보이려면 같은 공개 HTTPS 터널 또는 상시 호스팅 서버가 필요하고, 서버가 켜져 있어야 합니다. 터널 주소가 바뀌면 두 PC에서 다시 주소를 설정합니다. 확장 프로그램을 사용한다면 동봉한 host-server/chrome-extension 버전 0.2.0을 새로고침하고 연결 화면의 서버 주소를 같은 공개 URL로 설정하세요. AI 답변 품질은 호스트 서버의 Gemini 설정에 따릅니다. Windows 전용 코드이므로 Windows 화면에서는 직접 실행 검증하지 못했습니다.

assets의 이미지는 모션별 AI 4컷 시안을 실시간 잘라 보여주는 시험 버전입니다. 프레임 크기와 위치는 최종 도트 애니메이션 수준으로 픽셀 정렬되지 않았습니다.
