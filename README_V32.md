# ZOO:CAFE v32 — 개별 오브젝트 카페

카페 내부를 한 장의 완성 배경으로 사용하지 않습니다.
`assets/cafe/v32/base/room.png`는 빈 벽/바닥만 담당하고, 가구와 장식은 모두 별도 투명 PNG입니다.

## 직접 교체하기
예: 테이블 디자인을 바꾸려면 `assets/cafe/v32/furniture/table.png`만 같은 이름의 투명 PNG로 덮어쓰고 새로고침합니다.
의자, 러그, 카운터, 진열장, 커피머신, 책장, 창문, 메뉴판, 화분, 액자, 조명, 고양이 침대, 축음기, 입구 매트도 각각 별도 파일입니다.

오브젝트 위치는 `game.js`의 `cafeV32Layout` 배열에서 수정할 수 있습니다. 충돌은 바로 아래 `cafeSolids.splice(...)` 영역에서 관리합니다.
